# Confetti palette (proposed, 25 Nov 2026)

Drawn from the owner's "Confetti 3" photograph. Chosen by the owner with the deeper red. **Applied across the platform on 25 Nov 2026** (studio, public website, post designer, emails and the brand brief).

| Name | Hex | Role |
|---|---|---|
| Confetti Red | `#D90F2A` | Lead bright: buttons, big headlines, colour blocks |
| Magenta | `#D9087F` | Second bright: accents, script word |
| Marigold | `#F08A1C` | The orange: badges, highlights (Ink text only) |
| Berry | `#9E0962` | Headings, links, all small red-family text |
| Deep Ink | `#2A1A1D` | Body text (kept from the brand) |
| Petal | `#FCEEF8` | The pale pink: page and card background |
| Lilac Blush | `#F6DDF1` | Panels, sidebar, tiles |
| Orchid | `#D75DAB` | Decoration only (shapes, dots) |
| Gold | `#F5B544` | Small highlights, sparkles (Ink text only) |
| Teal | `#3A99B8` | One small pop per piece. Never text or backgrounds |

## Contrast (WCAG ratios)

| Pairing | Ratio |
|---|---|
| Deep Ink on Petal | 14.8 |
| Berry on Petal | 7.0 |
| White on Confetti Red | 5.2 |
| White on Magenta | 4.9 |
| Confetti Red on Petal | 4.6 |
| Confetti Red on Lilac Blush | 4.1 |
| Ink on Marigold | 6.6 |
| Ink on Gold | 9.2 |

## Rules

- Small red-family text uses Berry.
- Never white text on Marigold (2.5), Orchid (3.5) or Teal (3.3).
- Never Marigold or Orchid as text on light backgrounds.
- Never red text on Magenta or the reverse (1.1). Separate large red and magenta areas with Petal, white or Berry.
- Teal stays tiny: one dot or detail per piece.
